# Spigot (1.21.4)
Installation Steps:
- `./start`
- Sign eula.txt
- `./start`
- Whitelist yourself and your friends on the server console

# [Chunky](https://www.spigotmc.org/resources/chunky.81534/)

To preload your world as a square centered at 0,0 with a radius of 1000 chunks:
- `chunky radius 1000`
- `chunky start`
